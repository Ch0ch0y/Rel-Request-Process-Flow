# Auto Clicker - No Python Required

## Quick Start (Easiest)

Simply double-click one of these:

### Option 1: **click_here_to_start.bat** (Recommended)
- Simplest option
- No setup required
- Works with Windows built-in features

### Option 2: **AutoClicker.vbs**
- Double-click directly
- Pure VBScript, no batch needed

---

## How to Use

1. **Double-click `click_here_to_start.bat`**
2. **A dialog box will appear** - select a mode:
   - `1` = Scroll page (Page Up/Down)
   - `2` = Press spacebar
   - `3` = Arrow keys (random)
3. **Press Enter** to start
4. **Press Ctrl+C** in the command window to stop

- Very minimal and lightweight

## Troubleshooting

### "Windows cannot find the file"
- Make sure you're running the batch file from the correct directory
- Don't rename the .vbs file

### Nothing happens when I double-click
- Try right-clicking and selecting "Run as administrator"
- Ensure Windows Script Host is enabled (usually is by default)

### "Windows Script Host Access Denied"
- Right-click the .bat file → "Run as administrator"

### It won't stop with Ctrl+C
- Close the command window directly (X button)
- Or run: `taskkill /IM cscript.exe` in another command window
